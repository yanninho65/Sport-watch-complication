Ce que ça change (suite de choix-sport-tennis.zip) :
- Le score de JEUX du set en cours (tennis) arrive maintenant jusqu'à
  la montre. MatchResult (mobile) porte deux nouveaux champs optionnels
  `currentSetHomeGames`/`currentSetAwayGames`, remplis par
  LiveTennisApi.parseMatch à partir du dernier élément de chaque liste
  de `score.games` (l'API renvoie les jeux gagnés PAR SET ; le dernier
  élément est donc le set en cours). Nuls en football, nuls en tennis
  tant qu'aucun set n'a commencé.
- WatchSync relaie ces deux champs (+ le sport) à la montre via la Data
  Layer API (nouvelles clés `currentSetHomeGames`/`currentSetAwayGames`/
  `sport` dans la DataMap).
- Côté montre : MatchScore porte les mêmes champs + `sport` (chaîne
  brute "FOOTBALL"/"TENNIS"). MatchListenerService les lit depuis la
  DataMap. MatchClock.kt sait maintenant traduire DEUX vocabulaires de
  statut selon `match.sport` : celui de TheSportsDB pour le foot
  (inchangé), et un nouveau pour Live Tennis API
  ("upcoming"/"live"/"completed"/"cancelled") — la fonction `liveSetLabel`
  compose le libellé de set à partir du score de jeux reçu.
- Résultat visible sur le LONG_TEXT (emplacement central Zenith) pour un
  match de tennis en direct : "Alcaraz 2-1 Sinner · 3e set 4-3" au lieu
  de "Alcaraz 2-1 Sinner · live" (le statut brut affiché tel quel avant
  ce changement).
- FollowedMatchPrefs (téléphone) persiste/restaure aussi ces deux
  champs, pour que la carte "match suivi" survive à une fermeture de
  l'app.

Ce qui reste un TODO séparé (voir README, section "Choix du sport et
intégration tennis") :
- Le score du JEU en cours (`points`, ex. "30-15") n'est pas relayé —
  l'API le fournit déjà dans le même appel, rien ne l'empêche techniquement,
  juste pas fait ici.
- Les rendus compacts (SMALL_IMAGE / MONOCHROMATIC_IMAGE / SHORT_TEXT)
  n'affichent toujours que le score de sets, pas le set en cours.

Pas de nouvelle clé API ni de nouvelle dépendance : ce zip s'applique
par-dessus choix-sport-tennis.zip (déjà livré) sans rien y changer côté
sélecteur de sport ou recherche.
