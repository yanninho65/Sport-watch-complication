CE QUI A CHANGÉ DANS CETTE LIVRAISON :

1) Un match suivi par l'API ne bloque plus le repli Sofascore une fois
   TERMINÉ (MatchFollowService.kt) — correction d'un vrai bug, pas
   juste un réglage
   - Constat de Yann : "je veux que Sofascore dernière notif prime,
     toujours, sauf si je choisis autre chose" — et c'était censé être
     déjà le cas (voir livraison précédente), mais en pratique un match
     déjà terminé continuait à bloquer le repli.
   - Cause réelle : FollowedMatchPrefs (le match suivi par l'API) n'était
     vidé QUE sur arrêt MANUEL (bouton "Arrêter le suivi", dans
     MainActivity.stopFollowing()) — jamais quand le match suivi se
     terminait TOUT SEUL (la boucle de polling de MatchFollowService
     s'arrête d'elle-même dès que `current.isFinished`, sans jamais
     vider ces prefs). Or SofascoreNotificationListenerService.refresh()
     s'efface systématiquement dès que FollowedMatchPrefs contient
     quelque chose, fini ou pas — donc un match API fini restait
     "suivi" pour toujours aux yeux de cette vérification, jusqu'à ce
     que Yann rouvre l'app et arrête le suivi à la main (ce qu'il n'a
     souvent aucune raison de faire, puisque le suivi s'était déjà
     arrêté tout seul).
   - Correctif : dès que la boucle de polling se termine parce que le
     match est fini, MatchFollowService vide maintenant
     FollowedMatchPrefs ET relance immédiatement
     SofascoreNotificationListenerService (même schéma que
     MainActivity.stopFollowing(), qui le faisait déjà pour l'arrêt
     manuel) — donc si une notif Sofascore est active à ce moment-là,
     elle reprend la main sur la montre sans délai.
   - Résultat : la priorité est maintenant vraiment "Sofascore dernière
     notif, toujours, sauf pendant qu'un match API est activement en
     cours de suivi" — un match API fini ne compte plus comme "un autre
     choix" qui bloque Sofascore.

À VÉRIFIER SUR APPAREIL (pas testable depuis ici) :
- Laisser un match API se terminer naturellement pendant qu'une notif
  Sofascore d'un AUTRE match est active : la complication doit basculer
  sur cette notif Sofascore dans la foulée, sans avoir besoin de rouvrir
  l'app.
