CE QUI A CHANGÉ DANS CETTE LIVRAISON :

1) Tennis de table (et présumé volley) : nouveau sport couvert dans
   SofascoreNotificationParser.kt.
   - Le tennis et le tennis de table/volley partagent EXACTEMENT le
     même gabarit de ligne ("Xe set terminé : score - score Nom"),
     donc on les distingue par un signal mathématique : sur la ligne
     la plus RÉCENTE, si la somme des deux scores égale le numéro
     d'ordre du set (ex. "3e set terminé : 2-1" -> 2+1=3), c'est un
     décompte CUMULATIF de sets (tennis de table/volley) — au tennis,
     où ce sont des jeux du set qui vient de finir, cette égalité
     n'arrive jamais (les scores y sont toujours ≥6).
   - Dans ce cas : pas besoin d'additionner plusieurs lignes comme au
     tennis, la ligne la plus récente donne déjà le score total à
     jour. Le numéro du set EN COURS se déduit du dernier set terminé
     + 1 (ex. 3e set terminé -> statut "S4").
   - Testé mentalement sur l'exemple fourni (Choi H. - Wang J., 3e set
     terminé, 2-1) : donne bien homeScore=2, awayScore=1, statut "S4".
   - "S<N>" est déjà le format brut utilisé par TheSportsDB pour le
     volley (S1..S5) : affiché tel quel côté montre, sans code dédié.

2) But de foot sans minute (SofascoreNotificationParser.kt) : certaines
   notifs Sofascore (ligues moins couvertes) ne donnent ni minute ni
   buteur précis — juste "But: score - score NomÉquipe". Reconnu
   séparément (nouveau gabarit goalNoMinute), score extrait
   normalement, mais statut laissé VIDE plutôt que d'inventer une
   minute.

3) wear/MatchClock.kt + wear/ScoreComplicationService.kt : gestion
   propre du statut vide — la complication affiche alors juste le
   score, sans "?" ni séparateur devant rien.

4) README.md mis à jour en conséquence (nouvelle sous-section tennis
   de table/volley, exemple du but sans minute, limites connues).

À tester (après avoir réinstallé wear-debug ET mobile-debug) :
- Un match de tennis de table ou volley en cours doit afficher le
  score en sets + "S<N>" (numéro du set en cours), et "Fin" une fois
  terminé.
- Un but de foot sans minute (ligue peu couverte) doit afficher juste
  le score, sans rien devant.
- Un match de tennis "classique" (Samsonova, Kouamé...) doit continuer
  à se comporter exactement comme avant (pas de régression).
