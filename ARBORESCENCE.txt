CE QUI A CHANGÉ DANS CETTE LIVRAISON (par rapport à la précédente) :

1) Choix dernière notif / match précis pour le repli Sofascore.
   - SofascorePrefs.kt (nouveau) : persiste le mode (LATEST par défaut,
     ou CHOSEN) et, si CHOSEN, le `groupKey` système + un libellé
     d'affichage du match choisi.
   - SofascoreNotificationListenerService.kt : refresh() respecte
     désormais ce choix — suit le match choisi tant qu'il a encore une
     notif active, retombe automatiquement sur "dernière notif" sinon
     (match terminé/notif supprimée) plutôt que de ne plus rien
     afficher. Nouvelle fonction listAvailableMatches() (+ variante
     statique listAvailableMatchesIfConnected()) qui liste un
     SofascoreMatchOption (équipes + aperçu) par groupe de notifs
     actuellement actif, pour le sélecteur côté MainActivity. Code
     commun (extraction équipes/lignes) factorisé, partagé entre
     refresh() et listAvailableMatches() — pas de comportement changé
     sur la partie déjà livrée.
   - MainActivity.kt : nouveau bouton "Repli Sofascore : … (changer)",
     toujours visible, qui ouvre — dans la zone de recherche habituelle
     — une liste avec "Dernière notification (auto)" en tête puis un
     élément par match actif. Choisir un élément fixe le repli et le
     pousse immédiatement à la montre (refreshIfConnected()).
   - activity_main.xml : bouton buttonSofascoreFallback ajouté sous
     buttonNotificationAccess.

2) Sports proposés dans le sélecteur TheSportsDB changés pour :
   Football, Basketball, Handball, Rugby, Volleyball (remplace Football,
   Basketball, Baseball, Hockey sur glace, Football US). "Tous sports"
   reste en option par défaut.
   - Valeurs `strSport` vérifiées (pas juste devinées, pour éviter de
     reproduire le bug d'origine) : "Soccer" (foot), "Basketball",
     "Handball", "Rugby", "Volleyball" — via le mapping id/nom publié
     par TheSportsDB (all_sports.php).
   - MainActivity.kt : enum SportsDbSport mis à jour (HANDBALL, RUGBY,
     VOLLEYBALL remplacent BASEBALL, ICE_HOCKEY, AMERICAN_FOOTBALL),
     mapping des ids radio mis à jour.
   - activity_main.xml : RadioButton correspondants remplacés
     (radioSdbHandball, radioSdbRugby, radioSdbVolleyball).

3) README.md mis à jour en conséquence (nouvelle sous-section sur le
   choix dernière notif/match précis, liste de sports à jour, structure
   du projet complétée avec les 3 fichiers Sofascore — elle ne les
   listait pas encore, oubli des livraisons précédentes, corrigé ici).
